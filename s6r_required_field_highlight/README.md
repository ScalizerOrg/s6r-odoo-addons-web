# S6R - Required Field Highlight

**Version:** 18.0
**Author:** Scalizer

## Overview

This module makes required fields easier to spot on Odoo form views. Odoo's
native indication of a required field is a subtle border color change on the
input itself. This module adds a red asterisk (`*`) next to the label of any
empty required field, across all form views.

The asterisk disappears as soon as the field is filled in.
